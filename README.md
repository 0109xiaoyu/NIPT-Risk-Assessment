# 某地区孕妇NIPT数据的统计建模与异常判定分析

> 基于某地区孕妇的NIPT数据，综合运用统计建模与机器学习方法，构建从数据清洗、特征分析、风险分层到异常判定的完整分析框架。

## 项目概述

无创产前检测（NIPT）通过采集母体血液、分析胎儿游离DNA来筛查染色体异常。其检测效果受孕周、孕妇BMI、年龄等多种因素影响。本项目基于某地区孕妇NIPT数据，完成数据预处理、相关性分析、回归建模、聚类分组、生存分析、风险分层及异常判定，为不同BMI人群确定最佳检测时点，并构建女胎染色体异常的可解释判定规则。

## 一、数据预处理与质量控制

- 统一日期格式，剔除末次月经晚于检测日期的逻辑错误记录。
- 排除抽血次数为5的异常记录，筛选GC含量0.35~0.65、孕周70~175天的有效样本。
- **投票机制**：对同一抽血多次检验的记录，采用投票机制（原始读段数最高、比对比例最高、重复率最低、唯一比对读段数最高）筛选最优样本。
- 对缺失值按业务含义处理，对连续变量进行标准化，为后续建模做准备。

## 二、核心模型与分析方法

| 分析模块 | 使用方法 | 解决问题 |
|----------|----------|----------|
| 相关性分析 | Pearson & Spearman相关系数 | 筛选与Y染色体浓度显著相关的因素，剔除多重共线性 |
| 回归建模 | 多元线性回归、广义相加模型(GAM) | 量化各因素影响，捕捉非线性关系 |
| 聚类分组 | 高斯混合模型(GMM) + 惩罚函数 | 基于BMI自动分组，避免主观阈值和人数失衡 |
| 生存分析 | Kaplan-Meier(KM)曲线 | 确定各组95%成功率的检测时点 |
| 不确定性量化 | 蒙特卡洛模拟 | 给出最佳检测时点的置信区间 |
| 灵敏度分析 | 误差扰动模拟 | 评估测量误差对通过率的影响 |
| 多因素风险模型 | Cox比例风险模型 | 纳入年龄、体重等，计算风险评分并分层 |
| 异常判定 | 随机森林 + IF-THEN规则提取 | 对女胎染色体非整倍体进行判定与规则解释 |

## 三、主要结果与模型细节

### 1. Y染色体浓度影响因素
- **相关性筛选**：通过Pearson剔除强共线性特征（如体重与BMI），保留5个关键指标。Spearman分析显示，检测抽血次数（r=0.30）、X染色体浓度（r=0.34）与Y浓度显著正相关；BMI（r=-0.12）、18号染色体Z值（r=-0.10）呈负相关。
- **回归建模**：多元线性回归调整后R²=0.2884，广义相加模型（GAM）R²=0.4884，非线性模型拟合优度显著提升（BMI的EDoF=28.6，X染色体浓度的EDoF=36.1）。
- **结论**：孕周延长与BMI升高对Y染色体浓度呈负向效应，检测次数增加和X浓度升高有助于提升Y浓度。

### 2. BMI分组与最佳检测时点
- **GMM分组**：为避免主观设定阈值，采用高斯混合模型对BMI进行聚类。同时引入**均衡性惩罚函数**（Penalty = 各组人数标准差 + λ·假阳/假阴率标准差），避免分组人数差异过大影响估计。最终将BMI分为4组（人数分别为324、306、212、154）。
- **KM曲线分析**：在每组内，定义“失败事件”为 Y染色体浓度 < 4%。采用Kaplan-Meier方法估计“检测成功概率”曲线，曲线随孕周增加呈阶梯式下降。以**95%成功率为阈值**（即曲线与0.95参考线的交点），确定各组最佳NIPT时点。
- **蒙特卡洛模拟**：对检测时间基准进行扰动，通过Beta分布抽样失败概率，结合Logistic函数生成随机曲线，重复5000次模拟，给出最佳时点的95%置信区间。
- **灵敏度分析**：分别在1%、3%、5%测量误差水平下扰动Y浓度，结果表明各组通过率均高于80%，结果对测量误差不敏感。

| 组别 | BMI区间 | 最佳NIPT时点 | 95%置信区间 |
|------|---------|--------------|-------------|
| 1 | [20.70,30.62) | 13w+1 | [12w+2, 14w] |
| 2 | [30.62,32.90) | 16w | [15w+1, 16w+6] |
| 3 | [32.90,34.91) | 13w+5 | [12w+6, 14w+4] |
| 4 | [34.91,46.88) | 12w+6 | [12w, 13w+5] |

### 3. 多因素风险模型与优化分组
- **Cox比例风险模型**：将Y浓度<4%定义为风险事件，纳入年龄、身高、体重、抽血次数、怀孕次数、生产次数等协变量，计算个体风险评分（预后指数）。
- **风险分层**：按风险评分四分位数划分为低、中低、中高、高风险四组。
- **惩罚函数优化**：采用惩罚函数 \( \text{Penalty}_k(t) = t + \lambda \cdot \log(1 / (n_k(t)/N_k)) \) 综合考量时间早晚与组内样本稀疏度，选取惩罚最小的时间点作为最佳检测时点。
- **结果**：随着BMI升高，最佳检测时间提前。灵敏度分析同样验证了结果的稳健性。

| 风险组 | BMI区间 | 最佳NIPT时点 | 95%置信区间 |
|--------|---------|--------------|-------------|
| 低风险 | [20.70,30.18) | 14w | [13w+1, 14w+6] |
| 中低风险 | [30.18,31.88) | 13w | [12w+1, 13w+6] |
| 中高风险 | [31.88,33.86) | 11w+6 | [11w+0, 12w+5] |
| 高风险 | [33.87,46.88) | 11w+0 | [10w+1, 11w+6] |

### 4. 女胎异常判定规则
- **数据重采样**：原始数据中非整倍体个体占比较小，采用重采样方法平衡样本。
- **随机森林建模**：按BMI<32与BMI≥32分别建立随机森林模型，准确率接近100%，且训练集与交叉验证集准确率差异小，无明显过拟合。
- **IF-THEN规则提取**：基于特征重要性排序，比较异常与正常样本的中位值，形成清晰的判别规则。
  - *示例*：当13号染色体GC含量 < 0.378 且Z值 < 0.133时，异常风险高；当18号染色体GC含量 > 0.379 或Z值 > 0.868时，异常风险高。
  - 这些规则将复杂的模型结果转化为可解释的诊断依据，为临床提供明确参考。
