# 基于NIPT数据的孕妇风险分层与胎儿异常判定模型

## 项目概述

无创产前检测（NIPT）通过采集母体血液分析胎儿游离DNA，是产前筛查的重要手段。其检测效果受孕周、孕妇BMI、年龄等多种因素影响，最佳检测时点的选择与胎儿异常判定成为关键问题。

本项目基于某地区孕妇NIPT数据，建立了一套从数据清洗、特征工程、统计建模到机器学习判定的完整分析框架，实现了：
- 量化各因素对Y染色体浓度的影响；
- 基于BMI自动分组并确定各组最佳检测时点；
- 纳入多因素构建风险分层模型，优化分组与检测时点；
- 对女胎染色体非整倍体进行判定，并提取可解释的IF-THEN规则。

## 一、数据预处理与质量控制

- 日期标准化、缺失值处理，剔除末次月经晚于检测日期等逻辑错误记录。
- 排除抽血次数为5的异常记录，GC含量筛选（0.35~0.65），孕周筛选（70~175天）。
- 对同一抽血多次检验的记录，采用投票机制（原始读段数最高、比对比例最高、重复率最低、唯一比对读段数最高）筛选最优样本。
- 最终得到高质量分析数据集，用于后续建模。

## 二、核心分析方法与模型

| 模块 | 方法 | 解决问题 |
|------|------|----------|
| 相关性分析 | Pearson & Spearman相关系数 | 筛选关键影响因子，剔除多重共线性 |
| 回归建模 | 多元线性回归、广义相加模型(GAM) | 量化各因素对Y染色体浓度的影响，捕捉非线性关系 |
| 聚类分组 | 高斯混合模型(GMM) | 基于BMI自动分组，避免主观阈值 |
| 生存分析 | Kaplan-Meier曲线 | 确定各BMI组最佳NIPT检测时点（95%成功率） |
| 风险模型 | Cox比例风险模型 | 纳入年龄、体重等多因素，计算风险评分并分层 |
| 不确定性分析 | 蒙特卡洛模拟 | 评估最佳时点的置信区间 |
| 灵敏度分析 | 误差扰动模拟 | 检验检测误差对结果的影响 |
| 异常判定 | 随机森林 + IF-THEN规则提取 | 对女胎染色体非整倍体进行判定，提供可解释规则 |

## 三、主要结果

### 1. Y染色体浓度影响因素
- 检测抽血次数、X染色体浓度与Y浓度显著正相关；孕妇BMI、18号染色体Z值与Y浓度显著负相关。
- 广义相加模型R²=0.4884，较线性模型（R²=0.2884）显著提升，揭示非线性关系。

### 2. BMI分组与最佳检测时点
| 组别 | BMI区间 | 最佳NIPT时点 | 最佳检测区间 |
|------|---------|--------------|--------------|
| 1 | [20.70,30.62) | 13w+1 | [12w+2, 14w] |
| 2 | [30.62,32.90) | 16w | [15w+1, 16w+6] |
| 3 | [32.90,34.91) | 13w+5 | [12w+6, 14w+4] |
| 4 | [34.91,46.88) | 12w+6 | [12w, 13w+5] |

### 3. 多因素风险模型与优化分组
采用Cox比例风险模型，纳入年龄、身高、体重、抽血次数、怀孕次数等，计算风险评分并分为四组，重新确定BMI区间及最佳时点：

| 风险组 | BMI区间 | 最佳NIPT时点 | 最佳检测区间 |
|--------|---------|--------------|--------------|
| 低风险 | [20.70,30.18) | 14w | [13w+1, 14w+6] |
| 中低风险 | [30.18,31.88) | 13w | [12w+1, 13w+6] |
| 中高风险 | [31.88,33.86) | 11w+6 | [11w+0, 12w+5] |
| 高风险 | [33.87,46.88) | 11w+0 | [10w+1, 11w+6] |

### 4. 女胎异常判定规则
- 对原始数据重采样后，分别对BMI<32和BMI≥32人群建立随机森林模型，模型准确率接近100%。
- 提取IF-THEN规则，例如：当13号染色体GC含量<0.378且Z值<0.133时，异常风险高。具体规则见表。
