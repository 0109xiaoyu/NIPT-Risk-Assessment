# 某地区孕妇 NIPT 数据的统计建模与异常判定分析

> 基于 NIPT 数据的多模型融合与风险分层研究 —— 从相关性建模、生存分析到可解释规则提取的完整数据分析闭环

[![PyGAM](https://img.shields.io/badge/PyGAM-GAM-orange)]()

无创产前检测（NIPT）通过采集母体血液、分析胎儿游离 DNA 片段来筛查 13/18/21 号染色体非整倍体异常，其检测可靠性高度依赖胎儿性染色体浓度（男胎 Y 浓度 ≥ 4%，女胎 X 浓度无异常），且对**检测孕周时点**高度敏感：过早检测胎儿游离 DNA 浓度不足易致失败，过晚检测则压缩临床干预窗口。

本项目基于某地区（以高 BMI 人群为主）孕妇的 NIPT 真实检测数据，完成 **数据清洗 → 相关性分析 → 线性/非线性回归 → 无监督分组 → 生存分析定时点 → 蒙特卡洛不确定性量化 → 多因素风险分层 → 女胎异常可解释判定** 的完整建模闭环，回答四个递进问题：

| 问题 | 目标 | 方法 |
|:---:|:---|:---|
| Q1 | Y 染色体浓度与孕周、BMI 等指标的相关性与显著性建模 | Pearson / Spearman + 多元线性回归 + 广义相加模型（GAM） |
| Q2 | 按男胎孕妇 BMI 分组并确定各组最佳 NIPT 检测点，分析误差影响 | 高斯混合模型（GMM）聚类 + Kaplan-Meier 生存分析 + 蒙特卡洛模拟 + 灵敏度分析 |
| Q3 | 在 BMI 之外纳入年龄、身高、体重等多因素，建立更合理的分组与最佳时点 | 多因素 Cox 比例风险模型 + 风险评分分层 + 惩罚函数选点 |
| Q4 | 构建女胎染色体异常判定模型并输出可解释规则 | 重采样 + 随机森林 + IF-THEN 规则提取 |

## 1. 数据集

数据为某地区孕妇的 NIPT 检测记录（含男胎与女胎），主要字段及在建模中的角色如下：

| 字段 | 含义 | 建模角色 |
|------|------|----------|
| 孕妇代码 | 匿名 ID | 分组键 |
| 年龄 | 孕妇年龄 | 协变量 |
| 身高 | 孕妇身高 | 协变量 |
| 体重 | 孕妇体重 | 协变量 |
| 孕妇BMI | 身体质量指数 | **核心分组变量** |
| 检测抽血次数 | 抽血次序 | 特征 |
| 检测孕周 | 孕周（天） | 时间变量 |

| 胎儿是否健康 | 健康标签 | 假阳/假阴判定 |

### 数据侧写结论（EDA）

- **BMI**：男女组均近似正态分布，集中于 30–35，男胎组均值 32.28 / 中位数 31.88，女胎组均值 32.08 / 中位数 31.40，两组高度接近；
- **检测孕周**：男胎组多集中于较早孕周（均值 115.85 天），女胎组检测显著偏晚（均值 126.66 天）；
- **GC 含量**：近似正态、集中于 0.40，数据质量好；
- **X 染色体浓度**：男女组均近似正态（X 浓度经估计存在少量负值），Y 染色体浓度均值/中位数约 0.08。

## 2. 数据预处理

在分析各指标相关性时，孕周与日期格式不同，以**天数**为单位对日期格式标准化。主要清洗规则：

1. 剔除末次月经日期晚于检测日期的逻辑错误记录；
2. 排除极少数检验抽血次数为 5 的记录；
3. 缺失值与重复记录删除；
4. 筛选有效孕周 70–175 天、考虑 5% 误差的 GC 含量有效区间，得到分析数据集；
5. **投票机制**：对同一抽血多次检验的记录，按"原始读段数最高、比对比例最高、重复率最低、唯一比对读段数最高"各积 1 分，选取得分最高的检验样本保存；
6. 对连续变量进行标准化，为建模做准备；
7. Q3 在 Q1 筛选基础上进行假阳/假阴二次判定；Q4 针对非整倍体占比过小而进行重采样。

## 3. 问题一：Y 染色体浓度相关性建模与显著性检验

**思路**：Pearson 剔共线 → Spearman 看关联 → 线性回归打底 → GAM 捕捉非线性。

- **Pearson 相关分析**：BMI 与体重相关性高达 0.83，且体重与 Y 浓度相关性低，剔除体重；孕周与抽血次数强相关（0.75），但二者均与 Y 浓度强相关，均保留；
- **Spearman 相关性**（各指标均显著）：

| 指标 | Spearman r | p 值 |
|------|:---:|:---:|
| 检测抽血次数 | 0.30 | 0.00 |
| 检测孕周 | 0.09 | 0.01 |
| 孕妇BMI | -0.12 | 0.00 |
| 18号染色体的Z值 | -0.10 | 0.00 |
| X染色体浓度 | 0.34 | 0.00 |

- **多元线性回归**（调整后 R² = 0.2884）：检测抽血次数（+0.4914）与 X 染色体浓度（+0.4081）显著正向，孕周（-0.2952）与 BMI（-0.1280）显著负向，18 号 Z 值不显著（p=0.58）；
- **广义相加模型（GAM）**：离散变量（抽血次数、孕周）用因子函数、连续变量用平滑函数刻画，R² = **0.4884**，较线性模型提升约 69%。

> **结论**：孕周延长与 BMI 升高呈显著负向效应导致 Y 浓度下降；检测次数增加和 X 浓度升高有助于提升 Y 浓度；BMI 等因素与 Y 浓度存在复杂非线性关系。

## 4. 问题二：GMM 分组 + 生存分析确定最佳 NIPT 时点

**思路**：GMM 对 BMI 无监督聚类（避免人为设阈值）→ KM 生存曲线按 95% 成功率定最佳时点 → 蒙特卡洛给置信区间 → 灵敏度分析验误差。

- **GMM 分组 + 均衡性惩罚**：惩罚函数 `Penalty = 各组人数标准差 + λ·假阳/假阴率标准差`，避免分组人数差异过大，最终分为 4 组：

| 组别 | BMI 区间 | 人数 |
|:---:|:---|:---:|
| 1 | [20.70, 30.62) | 324 |
| 2 | [30.62, 32.90) | 306 |
| 3 | [32.90, 34.91) | 212 |
| 4 | [34.91, 46.88) | 154 |

- **生存分析设定**：将 `Y 浓度 < 4%` 定义为失败事件，KM 估计乘积结构天然满足"孕周越长失败风险越高"的单调约束；以 **95% 成功率为阈值**取最后一个达标孕周作为推荐时点；
- **蒙特卡洛模拟**：对局部失败概率按 `Beta(k+1, n-k+1)` 抽样，结合 Logistic 失败概率曲线生成随机曲线，重复 5000 次取 2.5%/97.5% 分位数构建区间；
- **灵敏度分析**：在 1% / 3% / 5% 误差水平下扰动 Y 浓度（`Y_noisy = Y × (1+ε), ε~N(0,σ²)`），各组通过率均高于 80%，波动小。

**结果**：

| 组别 | BMI 区间 | 最佳 NIPT 时点 | 95% 置信区间 |
|:---:|:---|:---:|:---|
| 1 | [20.70, 30.62) | 13w+1 | [12w+2, 14w] |
| 2 | [30.62, 32.90) | 16w | [15w+1, 16w+6] |
| 3 | [32.90, 34.91) | 13w+5 | [12w+6, 14w+4] |
| 4 | [34.91, 46.88) | 12w+6 | [12w, 13w+5] |

> **结论**：总体趋势为 BMI 越高最佳 NIPT 检测时间越应提前（BMI 与 Y 浓度负相关，高 BMI 者需尽早检测以避免浓度不足导致失败）。

## 5. 问题三：多因素 Cox 比例风险模型与风险分层

**思路**：在 BMI 基础上纳入年龄、身高、体重、抽血次数、怀孕/生产次数、读段相关比例等协变量，Cox-PH 半参数模型评估多因素对达标概率影响，不预设基线风险函数。

- 按风险评分（预后指数）四分位数分为**低 / 中低 / 中高 / 高**四组；
- 每组内 KM 估计生存函数，采用惩罚函数综合时点早晚与组内样本稀疏度：`Penalty_k(t) = t + λ·log(N_k / n_k(t))`，在 `Ŝ_k(t) ≥ 0.95` 的候选时点中取惩罚最小者为最佳时点；
- 同样采用蒙特卡洛模拟与灵敏度分析检验误差，各组通过率均在 80% 以上。

**结果**：

| 风险组 | BMI 区间 | 最佳 NIPT 时点 | 95% 置信区间 |
|:---:|:---|:---:|:---|
| 低风险 | [20.70, 30.18) | 14w | [13w+1, 14w+6] |
| 中低风险 | [30.18, 31.88) | 13w | [12w+1, 13w+6] |
| 中高风险 | [31.88, 33.86) | 11w+6 | [11w+0, 12w+5] |
| 高风险 | [33.87, 46.88) | **11w+0** | [10w+1, 11w+6] |

> **结论**：多因素风险分层下，随 BMI 升高最佳检测时间进一步提前，高风险组建议提前至 11w+0；灵敏度分析验证分组与时点划分稳健可靠。

## 6. 问题四：女胎染色体异常判定 —— 随机森林 + IF-THEN 规则提取

女胎不携带 Y 染色体，需依据 13/18/21 号染色体非整倍体判定异常，并综合 X 染色体及各染色体 Z 值、GC 含量、读段比例、BMI 等因素。

- **重采样**：原始数据非整倍体个体占比过小，先对原始数据进行重采样平衡类别；
- **分组建模**：BMI 为人体自身变量而非检验误差，按图 5-1 分布取 **BMI = 32** 为阈值将人群分为两类，分别建立随机森林模型（以非整倍体 / 假阳为判定目标）；
- **防过拟合验证**：各组模型训练集与交叉验证集准确率差距小，无明显过拟合，**准确率均接近 100%**；
- **IF-THEN 规则提取**：基于随机森林特征重要性排序，比较异常与正常样本中位值确定阈值 `τ_j = (median(x_j⁺) + median(x_j⁻)) / 2`，形成可解释判别规则。

**规则示例**：
- 当 13 号染色体 GC 含量 < 0.378 且 Z 值 < 0.133 时，异常风险高；
- 当 18 号染色体 GC 含量 > 0.379 或 Z 值 > 0.868 时，异常风险高；
- 假阳判断：BMI ≤ 32 时重复率 < 0.03、比对率 > 0.80、原始读段数 < 4685944.75 等落入假阳范围，说明检验结果不可靠，需重新采样检测。

> **结论**：将复杂模型结果转化为可解释的诊断依据，为临床提供明确的判定标准。

## 11. 结论与展望

- 孕周延长与 BMI 升高导致 Y 染色体浓度下降；检测次数增加和 X 浓度升高有助于提升 Y 浓度；
- GMM 分组与 Cox 风险分层均表明 BMI 越高最佳 NIPT 检测时点越应提前（高风险组提前至 11w+0）；
- 随机森林模型可有效判定女胎染色体异常，并输出可解释 IF-THEN 规则；
- 未来可引入深度学习模型，进一步提升对复杂非线性关系的刻画能力。
